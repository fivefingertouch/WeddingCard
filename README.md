# کارت دعوت هوشمند و مدرن مراسم عقد (مبتنی بر وب و گیت‌هاب)

کارت دعوت آنلاین، لوکس و تعاملی برای مراسم عقد و پیوند زوجین، با انیمیشن مینیمال گشودن پاکت نامه، پخش موسیقی رمانتیک، شمارش معکوس زنده، آدرس و مسیریابی هوشمند، فرم اعلام حضور (RSVP) و ابزار اختصاصی تولید لینک برای هر میهمان.

---

## 🌟 ویژگی‌های برجسته

1. **انیمیشن مینیمال و پاکت نامه با مهر و موم (Wax Seal)**:
   - باز شدن زیبا و چشم‌نواز با لمس یا کلیک
   - افکت ریزش گلبرگ و پولک‌های طلایی (Gold Confetti)
   - امکان مشاهده مستقیم و بدون انیمیشن برای راحتی کاربری

2. **لینک اختصاصی با نام هر میهمان**:
   - پشتیبانی از پارامترهای آدرس نظیر:
     ```
     https://username.github.io/wedding-card/?to=جناب+آقای+دکتر+محمدی
     https://username.github.io/wedding-card/?to=خانواده+محترم+رضایی
     https://username.github.io/wedding-card/?to=سارا+و+علی+عزیز
     ```
   - نمایش نام میهمان روی پاکت نامه، روبان خوش‌آمدگویی و بخش اعلام حضور

3. **ابزار تولید لینک هوشمند (Link Generator)**:
   - امکان ساخت لینک تکی با انتخاب پیشوند احترام (جناب آقای، سرکار خانم، خانواده محترم و...)
   - امکان تولید گروهی لینک با الصاق لیست نام میهمانان و دانلود خروجی اکسل/CSV
   - دکمه‌های ارسال مستقیم در **واتساپ**، **تلگرام** و **پیامک** همراه با متن ادبی و آماده دعوت

4. **مسیریابی هوشمند با برنامه‌های نقشه همراه**:
   - دکمه‌های مستقیم مسیریابی در **نشان (Neshan)**، **بلد (Balad)**، **گوگل مپ (Google Maps)** و **ویز (Waze)**
   - دکمه ذخیره رویداد در تقویم تلفن همراه (دانلود فایل `.ics` برای آیفون/اندروید و تقویم گوگل)

5. **فرم اعلام حضور و ثبت پیام شادباش (RSVP)**:
   - ثبت تعداد نفرات همراه (بزرگسالان و کودکان)
   - دیوار آرزوهای میهمانان (پیام‌های تبریک)
   - ذخیره‌سازی در مرورگر (LocalStorage)

6. **پخش‌کننده موسیقی ملایم و رمانتیک**:
   - تولید هارمونی‌های آرامش‌بخش با Web Audio بدون نیاز به فایل‌های صوتی سنگین و بدون مشکل فیلترینگ یا کپی‌رایت
   - قابلیت قطع و وصل آسان با دکمه شناور

7. **سازگاری کامل با GitHub Pages**:
   - ۱۰۰٪ استاتیک (بدون نیاز به سرور و دیتابیس خارجی)
   - همراه با فایل ورک‌فلو خودکار `.github/workflows/deploy.yml`

## 🚀 راهنمای راه‌اندازی روی GitHub Pages (رایگان)

1. در سایت [GitHub](https://github.com) یک مخزن (Repository) جدید به صورت Public با نام مثلاً `wedding-card` بسازید.
2. پروژه را به مخزن خود Push کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial Wedding Card"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO>.git
   git push -u origin main
   ```
3. به صفحه مخزن در گیت‌هاب رفته و به مسیر **Settings > Pages** بروید.
4. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** تنظیم نمایید.
5. پس از چند لحظه، کارت دعوت شما در آدرس زیر در دسترس خواهد بود:
   ```
   https://<YOUR_USERNAME>.github.io/<YOUR_REPO>/
   ```

## 🛠️ اجرای پروژه در محیط توسعه (Local)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه نهایی
npm run build
```
